# StockChecker — 部材価格・納期トラッカー

登録した部材の **一般価格・納期** をボタン 1 つでネットからまとめて取得し、見積取得が必要な部材を自動判定。
特注品やネットに無い部材は **仕入先へのメール (見積依頼・価格/納期確認・注文・督促) をワンタッチで下書き** し、
確認周期ごとのリマインド (設定により自動送信) まで行う、チームで共有できる Web アプリです。

## 機能

| 機能 | 内容 |
|---|---|
| 一括取得 | ホームの「価格・納期を一括取得」で、URL を登録した全部材 (または選択した部材) を順番に取得。進み具合を画面上部に表示し、途中で中止可能。自動では取得しません |
| アクセス制限対策 | サイトごとに間隔を空けて 1 件ずつアクセス (既定 3 秒、ミスミ 10 秒)。HTTP 429 や制限ページを受けたら待って再試行し、その回はそのサイトの間隔を自動で倍に。間隔・再試行回数は設定画面で変更可 |
| 価格推移グラフ | 部材ごとの単価・納期の推移 (ホバーで値表示)、全部材の推移一覧 (期間・担当で絞り込み) と期間内の変動ランキング、一覧のスパークライン |
| 見積必須判定 | 下表のルールで自動判定し、担当者へ通知 (メール / Slack・Teams) |
| ワンタッチメール | 部材画面・ホームのボタンで見積依頼 / 価格・納期確認 / 注文 / 督促の下書きを作成。一覧で複数選択すると **主仕入先ごとに 1 通にまとめて** 作成。文面はテンプレートを画面で編集可 |
| 回答管理 | 送信したメールは「回答待ち」になり、見積回答を記録するか「回答あり」を押すと回答済みに。設定日数 (既定 5 日) 回答が無いと督促をリマインド |
| 定期確認 | 特注品・URL の無い部材は確認周期 (既定 90 日・部材ごとに変更可) ごとに担当者へリマインド。部材ごと + 管理者の許可で **確認メールを自動送信**。督促の自動送信も設定可 |
| 発注・入荷 | 注文メールの送信で発注を自動登録 (Web・電話の発注は手動で記録)。納期回答・入荷 (分納可)・キャンセルを記録。納期回答が無い・入荷予定を過ぎた発注をリマインドし、納期確認メールをワンタッチで作成 |
| 受信メールの取り込み | 仕入先の返信 (.eml / Outlook の .msg、またはメールサーバー IMAP) を取り込み、送ったメールと自動で結び付けて本文から単価・納期・回答納期を読み取り。確認して「反映」すると価格の履歴・発注に記録 |
| Excel | テンプレートで部材・仕入先を一括登録 (取り込み前に新規・更新・エラーを確認)。部材一覧・価格推移・操作履歴を Excel で出力 |
| チーム共有・履歴 | ログイン不要 (全員同じ権限)。ブラウザごとに名前を選ぶと、すべての操作が「誰が・いつ・何を (変更前→変更後)」として操作履歴に残る。部材ごとのコメント、「自分の担当」表示 |

### 判定ルール

| コード | 条件 | 区分 |
|---|---|---|
| `no_price` | 価格情報がない | 要見積 |
| `custom_item` | 特注品 | 要見積 |
| `stale_price` | 価格情報が `SC_STALE_DAYS` (30) 日より古い | 要見積 |
| `price_change` | 前回比 ±`SC_PRICE_CHANGE_PCT` (10)% 以上の変動 | 要見積 |
| `over_budget` | 一般単価 > 予算単価 | 要見積 |
| `high_value` | 単価×数量 ≥ `SC_HIGH_VALUE_AMOUNT` (100,000) 円 | 要見積 |
| `lead_time_over` | 今日+一般納期 > 必要納期 | 要見積 |
| `stock_short` | 流通在庫 < 必要数 | 要見積 |
| `lead_time_tight` | 必要納期までの余裕 < `SC_LEAD_MARGIN_DAYS` (3) 日 | 注意 |

同じ部材・仕入先への見積依頼は、下書きが残っている間および送信後 `SC_STALE_DAYS` 日間は重複作成しません。

## ネットでの価格・納期の自動追跡

設定した取得元から、チェックのたびに一般価格・納期・在庫を自動取得します
(exe 版は `stockchecker.ini` の `[sources]`、Python 版は環境変数)。**AI なし・無料の取得元だけでも運用できます。**

| 取得元 | 費用 | 対象 | 設定 |
|---|---|---|---|
| 商品ページ監視 | 無料・キー不要 | モノタロウ・ミスミ等、商品ページが決まっている部材 | 部材の編集画面で URL を登録 (`SC_PAGE_WATCH=1` 既定) |
| Yahoo!ショッピング | 無料 | 汎用品・工具・消耗品 (品番で検索、税込→税抜換算) | `SC_YAHOO_APP_ID` |
| 楽天市場 | 無料 | 同上 | `SC_RAKUTEN_APP_ID` |
| Mouser / Digi-Key | 無料 | 電子部品 (品番完全一致・数量割引・メーカー納期) | `SC_MOUSER_API_KEY` / `SC_DIGIKEY_CLIENT_ID`,`_SECRET` |
| Web 検索 (AI) | 従量課金・任意 | 何でも。他で見つからない部材の最後の手段 | `ANTHROPIC_API_KEY` + `SC_WEB_SEARCH=fallback` |

- **商品ページ監視の使い方**: 部材画面の「商品ページの URL を貼り付けて価格を追跡」に URL を貼るだけ。
  部材の新規登録時も URL から品名・品番・メーカー・価格を自動入力できます。読み取りは次の順に試します:
  1. ページに埋め込まれた商品データ (schema.org JSON-LD / microdata / OGP)
  2. ページ内データの price 項目
  3. サイトごとに記憶した「価格の見出し」
  4. 「販売価格」「単価」などの見出しの近くの金額 (送料・ポイント等は除外、税込は税抜に換算)
  - 静的な HTML で見つからなければ、PC の **Edge / Chrome を裏で起動して JavaScript 実行後のページ**を読み直します
  - それでも判定できない場合は、ページ内の金額一覧から **どれが価格かを 1 回選ぶ**だけ。見出しをサイトごとに記憶し、
    同じサイトの他の商品も以後は自動で読めます
  - ログインしないと価格が見えないページ (会員価格など) は読めません。その場合は価格を手入力して URL だけ登録できます
- 複数の販売元を比較し、**必要数の在庫がある中で最安**を代表値として記録 (比較した全件とリンクも保存)
- 部材画面の「ネットで最新価格を取得」で即時取得も可能

> 取得した価格は参考値です。発注前に商品ページか正式見積で確認してください。
> 各サイトの利用規約に従い、巡回は定期チェック時 (既定 24 時間ごと) のみに留めています。

## exe で使う (Windows・Python 不要)

1. GitHub の **Actions → Build Windows exe** の最新実行の「Artifacts」から `StockChecker.exe` をダウンロード
   (または Windows 上で `build_exe.bat` を実行して `dist\StockChecker.exe` を生成)
2. 好きなフォルダ (例: `C:\StockChecker`) に置いてダブルクリック → ブラウザが開きます
3. 画面上部で **自分の名前を選びます** (ログインは不要。操作履歴に残る名前です)。
   「担当者・仕入先」または「Excel 一括登録」で担当者・仕入先・部材を登録してください
4. 同じフォルダに `stockchecker.ini` (設定) と `stockchecker.db` (データ) が作られます。
   データを残すにはフォルダごとバックアップしてください

### チームで共有する

1. 常時起動している PC (または社内サーバー) で `stockchecker.ini` の `[app]` に `share = 1` を設定して起動
2. 起動時の黒い画面と「設定」画面に表示されるアドレス (例: `http://PC名:5000/`) をメンバーに伝える
3. 初回は Windows のファイアウォールの許可を求められるので「プライベート ネットワーク」を許可
4. メンバーはブラウザでアドレスを開き、最初に自分の名前を選ぶだけで使えます

> データはその PC の `stockchecker.db` 1 つにまとまります。アプリを起動した PC の電源が入っている間だけ使えます。

### 運用の流れ

- **ネットで買える部材**: 部材画面に商品ページの URL を貼り付け → 必要なときにホームの「価格・納期を一括取得」
- **特注品・メール発注の部材**: 主仕入先を設定 → 「見積依頼」「価格・納期の確認」ボタンで下書き → 送信 →
  回答が来たら「見積回答・価格を記録」。確認周期ごとにホームの「確認時期」とメールでリマインド
- **発注**: 「注文」メールを送信すると発注が登録されます → 納期回答・入荷を「発注・入荷」画面で記録
- **仕入先の返信**: 「受信メール」画面に .msg / .eml をドラッグ (または `[imap]` を設定してボタンで取得) →
  読み取った単価・納期を確認して「反映」
- メールサーバー (SMTP) を `stockchecker.ini` の `[smtp]` に設定すると実際に送信されます
  (未設定の間は `outbox` フォルダに .eml を保存。Outlook 等で開いて送信できます)。自動送信は SMTP 設定時のみ動作します

> 初回は Windows SmartScreen の警告が出ることがあります (「詳細情報」→「実行」)。

## 使い方 (Python から)

```bash
pip install -r requirements.txt
python -m stockchecker seed            # デモデータ投入 (任意)
python -m stockchecker serve           # http://127.0.0.1:5000 (初回は管理者アカウントを作成)
```

価格の取得は画面のボタンで行います。スクリプトから実行したい場合 (任意):

```cron
0 8 * * 1-5  cd /path/to/StockChecker && python -m stockchecker check
```

`python -m stockchecker remind` で確認期限・回答待ちのリマインドを 1 回実行します (serve / exe では 30 分ごとに自動)。

## 設定 (環境変数)

| 変数 | 既定値 | 説明 |
|---|---|---|
| `SC_DATABASE` | `stockchecker.db` | SQLite ファイル |
| `SC_COMPANY_NAME` / `SC_PURCHASER_NAME` / `SC_PURCHASER_EMAIL` | サンプル値 | メール署名・差出人 |
| `SC_SMTP_HOST` / `SC_SMTP_PORT` / `SC_SMTP_USER` / `SC_SMTP_PASSWORD` / `SC_SMTP_STARTTLS` | 未設定 / 587 / - / - / 1 | SMTP。**未設定の場合は送信せず `SC_OUTBOX_DIR` に .eml を保存** |
| `SC_OUTBOX_DIR` | `outbox` | .eml 保存先 |
| `SC_AUTO_SEND` | `0` | 見積依頼の自動送信を全体で許可 |
| `SC_PRICE_FEED_URL` | 未設定 | HTTP 価格フィード。`GET {url}?part_number=..&maker=..` が `{"unit_price":..,"lead_time_days":..,"stock_qty":..}` (またはその配列) を返す |
| `SC_STALE_DAYS` 他 | 上表参照 | 判定しきい値 |

## 価格表 CSV

```csv
part_number,unit_price,lead_time_days,stock_qty,min_order_qty,currency,observed_at
STM32F407VGT6,1520,60,800,1,JPY,2026-09-29
```

`part_number` 以外は任意。未登録の品番はスキップして画面に表示します。

## 拡張

商社・通販サイトの API に対応するには `stockchecker/providers.py` の `PriceProvider` を継承して
`fetch(material)` を実装し、`app.build_providers` に追加してください。

## 構成

```
stockchecker/
  rules.py      見積必須判定 (純粋関数)
  service.py    判定・アラート・メール送信
  jobs.py       一括取得 (サイトごとの間隔・制限時の再試行・進捗)
  throttle.py   サイトごとのアクセス間隔の制御
  mailflow.py   メールテンプレート・ワンタッチ下書き・回答管理
  reminders.py  確認周期・回答待ちのリマインドと自動送信
  pagereader.py 商品ページの読み取り (ブラウザ表示・制限ページの判定)
  orders.py     発注・入荷 (分納・納期回答・遅れのリマインド)
  inbox.py      受信メールの取り込み・送信メールとの対応付け・単価/納期の抽出
  excel.py      Excel テンプレート・一括登録 (プレビュー)・出力
  providers.py  価格取得元 (HTTP / デモ / CSV)
  mailer.py     メール文面テンプレートと SMTP/.eml 送信
  app.py        Flask Web UI
  __main__.py   CLI (serve / check / seed)
tests/          pytest
```

テスト: `python -m pytest`
